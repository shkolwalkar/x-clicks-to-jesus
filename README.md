X Clicks to Jesus is a version of a Wikipedia game called '6 Clicks to Jesus.' In that game, players navigated to a random page on Wikipedia, and had 6 'clicks' to other articles. Within the 6 clicks, you had to reach the Wikipedia article about Jesus.

X Clicks to Jesus is a Java implementation of the same game, with some twists. For one, you can customize the number of 'clicks' which can make the game easier or harder.

In this Java implementation, you're navigated to a random Wikipedia article, and a list of articles linked to the random article are printed on the console. The player then 'clicks' by typing the name of article they wish to navigate to.
